# kod

Бесплатный тренажёр SQL прямо в браузере. Настоящая база данных, задачи
проверяются по результату запроса, а не по совпадению текста.

## Как это проверяет

Твой запрос и эталонный выполняются на одной и той же базе, и сравниваются
**наборы строк**, а не их порядок. Поэтому `SELECT name, age` и `SELECT age, name`
оба верны, если задача не про порядок, а `SELECT name` — нет, и приложение
объяснит, чего не хватает: «у эталона строк 8, колонок 1 против 2».

Ошибка синтаксиса не роняет страницу: база возвращает сообщение, приложение
показывает его и напоминает про кавычки, запятые и точку с запятой.

## Что внутри

- `index.html` — всё приложение: разметка, стили, логика. Без сборки, без фреймворков.
- `assets/sql-wasm.js`, `assets/sql-wasm.wasm` — SQLite, собранный в WebAssembly.
  Лежат в репозитории намеренно: **никакого CDN**. Интернет здесь медленный, а
  тренажёр должен открываться и без него.
- Шесть задач: `SELECT`, `WHERE` с двумя условиями, `GROUP BY` с `AVG`, `HAVING`,
  `JOIN` двух таблиц и `DISTINCT`.

## Схема

```
students(id, name, age, city, group_id)
groups(id, name, teacher)
grades(id, student_id, subject, score)
```

## Запуск

```bash
python3 -m http.server 8099   # и открыть http://127.0.0.1:8099
```

Не открывай через `file://` — браузер не даст прочитать `.wasm` с локального
диска, это ограничение безопасности, а не ошибка в приложении.
